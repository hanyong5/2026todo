## 1. 개요

| 항목 | 내용 |
|------|------|
| 한 줄 소개 | 서버·DB 없이 브라우저에서 바로 쓰는 개인용 할 일 관리 앱 |
| 목적 | 설치나 로그인 없이 빠르게 할 일을 기록하고 관리 |
| 대상 사용자 | 개인 사용자 (1인) |

## 2. 사용자 구분

1인용 개인 앱으로 로그인·회원 개념이 없다. 모든 기능은 단일 사용자가 사용한다.

## 3. 기능 요구사항

> 우선순위: 🔴 필수(Must) / 🟡 권장(Should) / ⚪ 나중(Later)

### 3.1 할 일 관리 (T)

| 번호 | 요구사항 | 우선순위 | 완료 기준 |
|------|----------|----------|-----------|
| T1 | 사용자는 할 일을 입력해 추가할 수 있다 | 🔴 | 입력창에 내용을 쓰고 추가(또는 Enter)하면 목록에 즉시 나타난다. 빈 값(공백만 포함)은 추가되지 않는다. |
| T2 | 사용자는 할 일을 완료/미완료로 전환할 수 있다 | 🔴 | 체크박스를 클릭하면 즉시 완료 상태(취소선 등)로 바뀌고, 다시 클릭하면 미완료로 돌아간다. |
| T3 | 사용자는 할 일의 내용을 수정할 수 있다 | 🔴 | 항목을 수정 모드로 전환해 내용을 바꾸고 저장하면 목록에 변경 내용이 반영된다. 빈 값으로는 저장되지 않는다. |
| T4 | 사용자는 할 일을 삭제할 수 있다 | 🔴 | 삭제를 누르면 해당 항목이 목록에서 즉시 사라지고, 새로고침 후에도 다시 나타나지 않는다. |
| T5 | 사용자는 전체 / 진행 중 / 완료 탭으로 목록을 거를 수 있다 | 🔴 | 탭을 선택하면 조건에 맞는 항목만 보인다. 해당 탭에 항목이 없으면 빈 목록 안내가 표시된다. |

### 3.2 데이터 저장 (S)

| 번호 | 요구사항 | 우선순위 | 완료 기준 |
|------|----------|----------|-----------|
| S1 | 할 일의 추가·수정·삭제·완료 상태 변경은 새로고침 후에도 유지된다 | 🔴 | 변경 즉시 브라우저 저장소(LocalStorage)에 기록되고, 새로고침이나 브라우저 재시작 후에도 동일한 목록과 상태가 그대로 표시된다. |
| S2 | 저장된 데이터가 없는 최초 접속 시 빈 목록으로 시작한다 | 🔴 | 저장소를 비운 상태로 접속하면 오류 없이 빈 목록 화면이 보인다. |

## 4. 비기능 요구사항

| 번호 | 분류 | 요구사항 |
|------|------|----------|
| N1 | 성능 | 서버 조회가 없어 초기 로딩과 모든 상호작용(추가·체크·필터 등)이 0.5초 이내로 반응한다 |
| N2 | 호환성 | 모바일(375px 기준)·태블릿·데스크탑 화면에서 레이아웃이 깨지지 않는다 |
| N3 | 저장 방식 | 서버·DB 없이 브라우저 LocalStorage만으로 데이터를 저장한다 |
